## Approach

Based on the website page, I followed these steps: 
1. Building an ML model with Scikit-learn
2. Creating a REST API to serve predictions using FastAPI
3. Containerizing the API using Docker

Buuuut, of course, I adjusted some things to make it spicier

4. A Streamlit frontend
5. User can choose the model!
